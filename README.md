# C Denemelerim

Bu klasör, C programlama dilini öğrenme sürecimde geliştirdiğim kodları, yaptığım denemeleri ve çözümlediğim problemleri içermektedir.

## Amaç
- **Pratik Yapmak:** Temel programlama mantığını C dili üzerinde uygulamak.
- **Kod Arşivi:** Öğrendiğim veri yapılarını ve algoritmaları kodlanmış halleriyle saklamak.
- **Hata Takibi:** Karşılaştığım problemleri ve çözümlerini kayıt altında tutarak gelişimi gözlemlemek.
